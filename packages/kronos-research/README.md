# OpenAlpha Kronos Research

Reproducible empirical studies of the Kronos financial foundation model.

The package keeps model integration under `openalpha_kronos.model`, shared
evaluation code under `openalpha_kronos.evaluation`, and completed studies
under `openalpha_kronos.studies`. Optional model, provider, GPU, and managed
runtime dependencies remain lazy so importing `openalpha_kronos` is safe in an
offline research environment.
